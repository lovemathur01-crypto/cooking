Exam Setup

How it works

  1. A class's normal classroom capacity equals its strength.
  2. Exam rooms have their own physical capacity; several classes are mixed in one room.
  3. Each class is split across rooms in continuous roll-number ranges, in proportion to class size.
  4. Same-class students are never seated next to each other (unless one class fills more than half a room).
  5. No student is skipped or repeated, and no room exceeds capacity.
